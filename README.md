# Buku Cerita Vita ✿

Buku Cerita Vita is a private journaling and storytelling application built for Vita. It offers a warm, calm, and safe space to record memories, sweet stories, and quiet days. 

## Features

- **Public & Private Entries**: Mark stories as public to show on the main feed, or keep them securely hidden in the private area.
- **Rich Text Editor**: A soothing, minimal editor experience with formatting tools, quote-of-the-day rotation, and tags (Senang, Inspirasi, Nyaman, Mimpi, Tenang).
- **Secure Access Control**: Integrated with Firebase Authentication to strictly limit access to the `Admin Area`. Only permitted emails (`alvitafabiola@gmail.com` and `shawtynewt@gmail.com`) can log in, edit, or delete the stories.
- **Modern Tech Stack**: Built with React, Tailwind CSS, Firebase (Firestore & Auth), and deployed beautifully to the web.

## Security

Only authorized users can access the private admin site to create, modify, or delete stories. Unrecognized Google accounts will be immediately rejected and logged out if they attempt to enter the Area Pribadi.
